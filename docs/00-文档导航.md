# 文档导航与阅读顺序

读者：计划部署或维护 Kubernetes 集群的管理员。目录整理日期：2026-11-10。
本目录按功能域组织现有文档；当前正式版本以根目录 [VERSION](../VERSION) 为准。
阅读位置写为“域编号.文档编号”，例如 `07.02`；编号表达推荐顺序，不表示脚本编号、版本或依赖执行顺序。
先读产品概览，了解功能、组件、架构与适用范围；其余内容按部署和运维任务查阅。

## 按任务选择路线

| 任务 | 建议阅读路线 |
| --- | --- |
| 了解产品 | 00.产品概览与架构 → 按需查看下方功能域 |
| 首次部署集群 | 01.01 部署指南 → 01.02 配置；受限网络先读 06.01；随后按需读 02.01、03.01 和 05.01 |
| 运维已有集群 | 04.01 功能说明 → 04.04 操作指南；修改配置时读 01.02，旧集群修复读 01.03 |
| 管理 LB 与业务入口 | 03.01 LB 运维管理 |
| 安装和使用监控中心 | 07.01 安装 → 07.06 运维门户 → 07.03 配置与维护 → 07.04 故障定位 |

## 维护约定

- 新文档优先进入已有功能域，文件名采用 `序号-中文名称.md`；必要的产品名、版本和日期可保留。
- 用户文档保留阅读位置与导航链接；顺序调整同时更新入口与引用，不改变脚本入口或功能编号。
- 用户文档优先说明功能、组件、架构、用户收益和操作方式；测试及发布过程记录不进入用户阅读路线。
- 文件整理不修改已发布 tag/Release；旧 tag 中的原路径仍按该历史版本保留。
