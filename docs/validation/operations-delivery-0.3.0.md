## 使用边界

- 首批离线平台为 Ubuntu 24.04 amd64；插件、业务镜像、认证凭据和系统补丁仓库单独准备。
- 不支持跨激活物料 ID 自动迁移；有活动物料时补丁预览先拒绝。升级目标仓库/镜像由独立流程准备。
- 不包含控制面成员变更、跨 minor 升级、通用数据库导出/恢复或生产原位 etcd 恢复。
- 控制面恢复、ConfigMap 数据保留及密文登记不能证明 PVC/应用数据库恢复。
- 本轮实际变更只在独立测试环境执行，不表示已升级用户原生产集群或证明全程零中断。
