# 07.06 运维门户页面与组件入口清单

内网验证环境的统一入口是 [Atlas KubeKit 运维门户](https://ops.monitoring.home.arpa/)。使用现有 AS 账号登录后，可搜索看板、日志探索、采集目标、规则和告警页面。门户部署在独立监控集群中，各目标系统继续执行自身的权限校验。

### 安装与更新

03 脚本菜单 19 在监控中心的 HTTPS/OIDC 入口验证通过后自动部署门户，并在安装报告中输出地址。门户使用独立域名 `ops.<监控基础域名>`，与其他三个组件共用 HTTPS 网关及 OIDC 策略。为门户配置指向入口 VIP 的 DNS 记录（或通配符解析），并确保证书覆盖门户域名。旧的 Grafana `/ops/` 书签会跳转到门户。所有组件链接在新标签页打开，门户保留搜索和展开状态。业务集群的 Agent 安装流程会跳过门户。

安装时读取监控命名空间中带 `grafana_dashboard=1` 标签的看板 ConfigMap。新增看板或更新入口后，可单独运行以下命令刷新门户。将域名替换为已配置的监控基础域名，使用目标监控集群的 kubeconfig：

```bash
python3 scripts/addons/monitoring_portal.py --domain monitoring.home.arpa
```

菜单 19 自动沿用所选镜像源。独立运行时可用 `--source-config` 指定同格式的源配置。已发布、已启用鉴权的业务集群工具可通过 `--links <文件>` 登记，菜单 19 使用环境变量 `ATLAS_PORTAL_LINKS_FILE` 接收同一文件。文件内容示例：

```json
[{"group":"生产集群 A","name":"Longhorn 卷与副本","url":"https://storage-a.example.com/"}]
```

附加入口对门户使用者可见。每项只填写页面地址，由目标系统校验访问权限。重新执行时省略文件会保留已登记的入口，传入空数组会清除它们。

以下清单按 2026-11-21 验证环境整理。已发布的三个组件域名也是独立入口，集群内部的诊断页面按需接入。

## 其余组件从哪里看

| 对象 | 推荐查看位置 |
| --- | --- |
| Prometheus Operator，ServiceMonitor、PodMonitor、PrometheusRule、AlertmanagerConfig | Prometheus 的服务发现、目标、规则和 Alertmanager 状态用于看生效结果；变更失败时再查对应 Kubernetes 资源的状态、事件以及 Operator 日志 |
| node-exporter、kube-state-metrics、API Server、etcd、scheduler、controller-manager、kubelet、kube-proxy、CoreDNS、业务应用指标 | 从相应 Grafana 看板或 Prometheus Targets/Query 查看。Exporter 的首页或 `/metrics` 主要提供抓取信息 |
| Loki Canary、Prometheus/Alertmanager/Alloy 配置重载边车、Grafana 看板与数据源边车、Loki 规则边车 | 看探测指标、重载结果、容器日志和目标系统中的生效配置。Loki Canary 用于检查测试日志写入和读回 |
| Atlas 通知中继、渠道适配器 | 从告警对象、接收器、投递指标和中继日志跟踪失败。企微、钉钉、飞书、SMTP 是外部投递目的地；Webhook 或凭据不进入页面目录 |
| Keepalived、VIP、内网 DNS、独立观察器 | 看 VIP 归属、切换记录、DNS/HTTPS 探测，以及集群外观察器的报告与通知。监控集群不可用时，保留集群外查询与接收通知的方式 |
| CSI、持久卷与业务存储 | Grafana 持久卷页查看容量，Prometheus 查看已接入的存储指标。卷操作进入所属集群配置的存储管理界面 |
| Remote Write、Loki Push、JWKS、就绪探针 | 分别供指标上送、日志上送、令牌验签和健康检查使用。门户可呈现检查结果，页面目录仅登记人员可使用的入口 |

## 门户接入约定

1. **首页优先放值班动作。** 看集群、查日志、查告警、管理静默、查采集目标；组件级页面放在“平台诊断”，业务侧入口先选集群，再选实例。
2. **地址来自安装或集群注册配置。** 已启用且有可达 HTTPS 地址的页面才生成导航。仅集群内可达的页面标明访问方法；未启用的可选组件不生成链接。
3. **登录后回到原页面。** 门户沿用独立 AS。邮件和机器人中的日志链接应直接回到 Grafana Explore，保留查询和时间窗口；用户已经有有效会话时直接打开。验收应从真实通知点击到查询结果，仅验证根地址返回 302 不足以确认整条链路。
4. **权限以目标系统或网关为准。** 区分只读查看、静默变更、数据源管理、存储操作和身份管理。隐藏菜单只影响导航，直接访问 URL 时仍需校验权限。

部署关系见[监控中心与业务集群架构图](05-监控中心与业务集群架构图.md)。故障排查见[监控故障定位指南](04-监控故障定位指南.md)。
